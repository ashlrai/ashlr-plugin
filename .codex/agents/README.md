# Ashlr Codex Agents

These are Codex-native companion prompts for Ashlr workflows:

- `ashlr-explorer.md` maps unfamiliar code with read-only, low-token habits.
- `ashlr-worker.md` implements scoped, disjoint slices when parallel work is useful.

They are intentionally separate from the Claude Code agent prompts under
`agents/`, which use Claude-specific model and `Task` terminology.
