## npm CLI and MCP entrypoints

With [Bun](https://bun.sh/) installed:

```sh
npm install -g ashlr-plugin
```

The package exposes `ashlr-plugin` and `ashlr-mcp`. Installing it does not register a host or approve its tools.

## Claude Code

```sh
curl -fsSL https://plugin.ashlr.ai/install.sh | bash
/plugin marketplace add ashlrai/ashlr-plugin
/plugin install ashlr@ashlr-marketplace
/reload-plugins
```

Run `/ashlr-status` to verify. If the plugin is not visible, fully quit and restart Claude Code. Use `/ashlr-doctor` for diagnostics.

## Codex

```sh
git clone https://github.com/ashlrai/ashlr-plugin
cd ashlr-plugin && bun install
codex plugin marketplace add ashlrai/ashlr-plugin
codex plugin add ashlr@ashlr-marketplace
bun run scripts/cli.ts codex-doctor --json
```

The checkout includes `.codex-plugin/plugin.json`, `.mcp.json`, workflow skills, and nudge-first hooks.

## Cursor

Back up or merge any existing MCP config before applying the repository example. Replace the example clone path with your absolute path.

```sh
git clone https://github.com/ashlrai/ashlr-plugin
cd ashlr-plugin
bun install
ASHLR_ROOT="/home/you/ashlr-plugin"
sed "s|<ASHLR_PLUGIN_ROOT>|$ASHLR_ROOT|g" \
ports/cursor/mcp.json > ~/.cursor/mcp.json
```

Restart Cursor after saving.

## Goose

Replace the example clone path with your absolute path.

```sh
git clone https://github.com/ashlrai/ashlr-plugin
cd ashlr-plugin
bun install
ASHLR_ROOT="/home/you/ashlr-plugin"
sed "s|<ASHLR_PLUGIN_ROOT>|$ASHLR_ROOT|g" \
ports/goose/recipe.yaml > my-ashlr-recipe.yaml

goose run --recipe my-ashlr-recipe.yaml
```
