## npm CLI and MCP entrypoints

With [Bun](https://bun.sh/) installed:

```sh
npm install -g ashlr-plugin
```

The package exposes `ashlr-plugin` and `ashlr-mcp`. Installing it does not register a host or approve its tools.

## Claude Code

```sh
curl -fsSL https://plugin.ashlr.ai/install.sh | bash
/plugin marketplace add ashlrai/ashlr-plugin
/plugin install ashlr@ashlr-marketplace
/reload-plugins
```

Run `/ashlr-status` to verify. If the plugin is not visible, fully quit and restart Claude Code. Use `/ashlr-doctor` for diagnostics.

## Codex

```sh
codex plugin marketplace add ashlrai/ashlr-plugin
codex plugin add ashlr@ashlr-marketplace
ashlr-plugin codex-doctor --json
```

The plugin package includes `.codex-plugin/plugin.json`, `.mcp.json`, workflow skills, and nudge-first hooks.

## Cursor

`ashlr-mcp` must be on PATH. The command below replaces `.cursor/mcp.json`. Merge it with an existing config if you already have other MCP servers.

```sh
npm install -g ashlr-plugin
ashlr-plugin tools --json
mkdir -p .cursor
cat > .cursor/mcp.json <<'EOF'
{
  "mcpServers": {
    "ashlr": {
      "command": "ashlr-mcp",
      "args": [],
      "env": {
        "ASHLR_MCP_HOST": "cursor"
      }
    }
  }
}
EOF
```

Restart Cursor after saving.

## Goose

`ashlr-mcp` must be on PATH. The command writes `ashlr-goose.yaml` in the current directory and runs it.

```sh
npm install -g ashlr-plugin
ashlr-plugin tools --json
cat > ashlr-goose.yaml <<'EOF'
version: "1.0"
title: ashlr token-efficiency suite
description: Registers the ashlr MCP router as one Goose extension.
extensions:
  - name: ashlr
    type: stdio
    cmd: ashlr-mcp
    args: []
    env:
      ASHLR_MCP_HOST: generic
EOF
goose run --recipe ashlr-goose.yaml
```
