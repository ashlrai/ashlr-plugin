---
title: What is ashlr?
description: Open-source Codex and Claude Code plugin. Agents install the CLI, call it with JSON output, and register the MCP server. Opt-in telemetry.
---

ashlr is a Codex and Claude Code plugin that replaces high-volume `Read`, `Grep`, `Edit`, and `Bash` workflows with lower-token alternatives, tracks what it saves, and surfaces the ledger through MCP tools, CLI commands, Codex skills, and the Claude Code status line.

On the 2026-10-17 reference run, reads were about 75% smaller and greps about 27% smaller per call. Per-repo means on that run were about 60% on vercel/ai, about 63% on pandas, and about 55% on tokio. That is not a whole session. MIT-licensed. Telemetry is off by default and explicit opt-in only. Works with Codex, Claude Code, Cursor, Goose, and generic MCP hosts.

See [savings math](/docs/concepts/savings-math) for the methodology.

## How an agent uses it

1. Install the CLI and the MCP command.
2. Call `ashlr-plugin tools --json` and `ashlr-plugin stats --json`.
3. Register `ashlr-mcp` for Claude Code, Cursor, or Codex. Snippets are in the repository `llms-full.txt` and on [llms-full.txt](/llms-full.txt).

## What the tools change

1. Large file reads keep the head and the tail. The middle is snipped.
2. Search can use a project genome when `.ashlrcode/genome/` exists. Without one, it falls back to a shorter ripgrep result.
3. An edit returns a diff summary instead of the whole file.

## Install

```sh
npm install -g ashlr-plugin
ashlr-plugin tools --json
```

Claude Code plugin:

```sh
curl -fsSL https://plugin.ashlr.ai/install.sh | bash
```

See [Install](/docs/getting-started/install) for Codex, Cursor, and Goose.

## What's included

| Layer | What you get |
|---|---|
| 54 MCP tools | Token-efficient file, search, edit, bash, SQL, HTTP, diff, logs, genome, GitHub |
| 37 slash commands + Codex skills | `/ashlr-status`, `/ashlr-savings`, `/ashlr-tour`, plus Codex doctor/savings/genome workflow skills |
| Status surfaces | Claude Code status line, Codex MCP/CLI savings, local stats ledger |
| Genome loop | Auto-extracts architectural knowledge into `.ashlrcode/genome/` |
| Savings badge | Embeddable SVG you can drop into your repo README |
