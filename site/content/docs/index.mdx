ashlr is the open-source token ledger for AI coding tools. Agents install it, call the CLI with `--json`, and register the MCP server. Humans use the same path.

**Per-call savings: reads about 75% smaller, greps about 27% smaller (not a whole session).** The same 2026-10-17 run's per-repo means were about 60% on vercel/ai, about 63% on pandas, and about 55% on tokio. Reproduce with the benchmark script. ([methodology](/docs/concepts/savings-math))

MIT-licensed. Telemetry is off by default and explicit opt-in only. Codex gets a plugin manifest, MCP config, workflow skills, and nudge-first hooks. Claude Code gets slash commands and a status line. Cursor and Goose register the same MCP router.

Agent index: [llms.txt](/llms.txt). Runnable reference: [llms-full.txt](/llms-full.txt).

## Install

One command for the CLI and `ashlr-mcp`:

```sh
npm install -g ashlr-plugin
ashlr-plugin tools --json
ashlr-plugin stats --json
```

Claude Code plugin:

```sh
curl -fsSL https://plugin.ashlr.ai/install.sh | bash
```

Codex plugin commands, and the Cursor and Goose files, are on the [install page](/docs/getting-started/install). MCP snippets for Claude Code, Cursor, and Codex are in the repository `llms-full.txt`.
