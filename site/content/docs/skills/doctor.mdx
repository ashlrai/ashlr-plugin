title: /ashlr-doctor
description: "Diagnose plugin installation, dependencies, MCP registration, hooks, stats, genome, and settings."
---

Run `/ashlr-doctor` in Claude Code, or `ashlr-plugin doctor` in a terminal. The command runs `scripts/doctor.ts` and prints its diagnostic output with suggested fixes. Check the final warnings and failures before applying fixes.

The MCP router hosts the tools in one process. Historical examples showing 15 responsive MCP servers describe the retired per-tool process layout.

Use `/ashlr-doctor --errors` for recent deduplicated errors. This replaces the removed `/ashlr-errors` command.
