## What it does

Runs `bun run ${CLAUDE_PLUGIN_ROOT}/scripts/doctor.ts` and prints the report verbatim. Sections:

- **install** : plugin root, Bun version, key dependencies, phantom presence
- **companions** : other Ashlr tools on this machine (phantom, locus, lexicon, ashlr-md, ashlr-stack), probed via `--ashlr-handshake` with a 2-second timeout; informational only and never counted as warnings or failures
- **mcp servers** : each registered server listed with the tools it serves
- **runtime state** : stats file, genome presence and manifest freshness, settings, tool allowlist, status line, pro status, summarizer model, project hint
- **cloud** : health ping to `https://api.ashlr.ai`; unreachable is a warning only, and `ASHLR_API_URL_DISABLE=1` suppresses the check
- **summarizer routing** : which provider summaries will use right now
- **hooks** : hook files present, plus a hook-performance section when timing data exists

Every `⚠` or `✗` line carries its own `fix:` hint. The report ends with `N warnings · M failures`; any non-zero count means apply the printed fixes. `--json` prints the same report as machine-readable JSON.

`/ashlr-doctor --errors` appends recent deduplicated errors from `scripts/errors-report.ts`, replacing the removed `/ashlr-errors` command.
