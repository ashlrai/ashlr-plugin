The plugin ships **39 slash commands**. Run `/ashlr-help` in Claude Code or browse the current command reference below.

### /ashlr-allow

Auto-approve every ashlr MCP tool so Claude Code stops prompting in bypass-permissions mode.

### /ashlr-benchmark

Run the ashlr-plugin token-savings benchmark against the current project.

### /ashlr-brief

Set response shortening (lite, standard, or concise) to cut filler from replies by about 30–55%; code, errors and destructive-action warnings stay intact.

### /ashlr-budget

Set, check, or clear a session spend cap. Guards against runaway tool use in long sessions.

### /ashlr-compact

Identify stale tool results accumulating in the conversation history and surface a recompression plan.

### /ashlr-dashboard

Rich token-savings dashboard ; per-tool bar charts, 7d/30d sparklines, projected annual savings, and cost in dollars.

### /ashlr-doctor

Diagnose an ashlr-plugin install ; checks plugin path, version, MCP servers, hooks, stats, genome, and settings in under 10 seconds.

### /ashlr-eco-mode

Toggle eco mode ; aggressive token-saving behaviors that trade some response richness for lower session cost.

### /ashlr-fleet

Explain the Phantom fleet pane, local peers, and governed Claude model routing.

### /ashlr-genome-init

Create .ashlrcode/genome/ in this project so ashlr__grep can search an indexed summary of the code. Run once per repo.

### /ashlr-genome-keygen

Create this machine's X25519 key for encrypted team genomes and register the public half. Run once per machine; safe to re-run.

### /ashlr-genome-loop

Inspect and control the automatic genome propose + consolidate loop (PostToolUse observer + SessionEnd consolidator).

### /ashlr-genome-push

Upload the local genome to the team cloud. Runs automatically at session end; run it by hand after a change. No-op if the team genome is not set up.

### /ashlr-genome-rewrap

Re-wrap the team genome key for members who joined or rotated their keypair. Admin only; run after a teammate runs /ashlr-genome-keygen --force.

### /ashlr-genome-team-init

Set up a team-cloud genome for this repo. Admin only, once per repo; re-run with --wrap-all to add new members.

### /ashlr-handoff

Generate a context-pack for the next session to resume cold.

### /ashlr-help

List every ashlr slash command with a one-line description, grouped by category.

### /ashlr-hook-timings

Show per-hook latency report (p50/p95/max) from hook-timings.jsonl.

### /ashlr-leaderboard

Opt in or out of the public savings leaderboard (off by default). When on, your GitHub handle and totals are shown publicly, never your email. Pro or Team only.

### /ashlr-legend

Decode every element of the ashlr status line (plain-text legend).

### /ashlr-ollama-setup

Diagnose and guide local Ollama install so `/ashlr-genome-init --summarize` works reliably. Recommends a fast 3B model and smoke-tests it.

### /ashlr-orchestrate-status

Inspect past /ashlr-orchestrate runs ; list recent runs or drill into a single graph by id.

### /ashlr-orchestrate

Turn a goal into a task graph, preview it, then run it once you confirm (Pro and Team only).

### /ashlr-parallelize

Spawn N parallel sub-agents ; one per file ; each applying the same task instruction. Merges results into a unified report.

### /ashlr-report-crash

Upload a recent ashlr-plugin crash dump to the maintainer. Opt-in, already-redacted, one report per invocation. Gives the founder faster bug signal when something in the plugin threw.

### /ashlr-resume

Resume your last coding session ; shows what you were doing, which files were active, and suggested next steps.

### /ashlr-savings

Show estimated tokens and cost saved by the ashlr-plugin this session and lifetime.

### /ashlr-selftest

Run every ashlr command's entry point against a throwaway fixture repo with --json and report pass/fail per command.

### /ashlr-settings

View or change ashlr-plugin settings.

### /ashlr-spawn

Run a named delegation pattern (for example triage-issues or pr-review-sweep) as one or more sub-agents.

### /ashlr-start

First-run setup wizard. Checks health, permissions, a live demo, genome setup, and a Pro overview in about a minute. Re-run any time; --reset re-arms it.

### /ashlr-status

Report the ashlr-plugin activation status and MCP server health.

### /ashlr-team-invite

Invite someone to your ashlr team by email. Sends a magic-link invite (admin role required).

### /ashlr-tier

Run a task in three model-tier phases. Explore on haiku, implement on sonnet, then do an integration check on haiku. Routing is automatic.

### /ashlr-tour

60-second guided walkthrough of the ashlr-plugin on the current project ; proves the value of the tools on real files.

### /ashlr-update

Update the ashlr-plugin to the latest version from its git remote.

### /ashlr-upgrade

Upgrade from Free to Pro or Team in the terminal in about 90 seconds, using GitHub sign-in or email, then Stripe checkout.

### /goal

Create a goal, split it into milestones, and run the next one in a sandbox that only proposes changes.

### /loop

Advance every enrolled repo toward its goals in one pass (default) or continuously with --watch. Proposal-only.
