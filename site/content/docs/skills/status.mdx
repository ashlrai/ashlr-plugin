## When to use

After install, after upgrading, or whenever you want a quick confirmation that the plugin is active.

## What it does

Reports a compact status block:

1. **Plugin version** : from `.claude-plugin/plugin.json`
2. **MCP server** : calls `ashlr__savings` and marks reachable when it returns
3. **Genome** : whether `.ashlrcode/genome/` exists in the current directory
4. **Core library** : `@ashlr/core-efficiency` version when accessible
5. **Session savings** : calls and tokens saved this session, from `ashlr__savings`

## Output

```
ashlr-plugin v1.37.1
  server:  ✓ reachable
  genome:  ✓ (.ashlrcode/genome found)
  core:    @ashlr/core-efficiency@0.3.0
  session: 12 calls, ~8,450 tokens saved
```

A **Telemetry snapshot** section is appended by default (`--telemetry` selects it explicitly): LLM provider, embedding-cache stats, genome fire-rate, block-to-call conversion, and opt-in telemetry state. `--context` appends the embedding-cache report from `scripts/context-status.ts`.
