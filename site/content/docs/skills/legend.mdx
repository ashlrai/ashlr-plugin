## When to use

Any time you see something in the status line you don't recognize. Also useful to share with teammates new to ashlr.

## What it does

Runs `scripts/print-legend.ts` and displays its static output. The legend covers the core status-line segments; the [Status line](/docs/concepts/status-line) reference also explains optional badges, cost estimates, and when fields are hidden.
