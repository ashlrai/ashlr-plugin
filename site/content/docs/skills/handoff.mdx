## When to use

At the end of a long session, or before switching machines. The handoff prints a plain-text block you can paste into the next session so the new agent starts with branch state, recent commits and genome status, without re-reading every file.

## What it does

Runs `bun run ${CLAUDE_PLUGIN_ROOT}/scripts/savings-dashboard.ts --handoff` and prints the output verbatim. The block contains:

1. Generation time and working directory
2. Branch and uncommitted file count
3. Last 5 commits (`git log --oneline`)
4. Genome state: present at `.ashlrcode/genome/`, or not initialized
5. Session calls and top 5 tools, only when `stats.json` has a top-level `session` bucket (the legacy v1 layout; the current v2 file keys sessions by id, so this part is usually absent)
6. Top 3 projects by call count, from `~/.ashlr/session-log.jsonl`

Git lines are skipped outside a repository, and each part is skipped when it has no data. The output is plain ASCII with no colors, so it pastes cleanly into a terminal or chat.

## Output (example)

From a fresh one-commit repo with a sample session log:

```
# ashlr handoff — paste into next session for cold-start context

Generated:   2026-11-22T16:45:24.821Z
Working dir: /home/you/code/api
Branch:      main  (1 uncommitted file)

Recent commits:
  7b57cec feat: initial

Genome:      not initialized (/ashlr-genome-init to add)

Top projects (recent):
  api                                      16 calls · 3 tools
  site                                     6 calls · 2 tools

Tip: run /ashlr-savings or /ashlr-dashboard for the rich view.
```
