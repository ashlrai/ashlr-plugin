Claude Code ships **37 slash commands** from `commands/`. Type `/ashlr-` to discover the Ashlr-prefixed commands; `/goal` and `/loop` are also included. Codex uses its packaged workflow skills and the `ashlr-plugin` CLI.

## Command inventory

This inventory matches `commands/*.md`. Descriptions summarize the command frontmatter. Run `HOME=$(mktemp -d) bun test __tests__/docs-freshness.test.ts` to check it against source.

## Separate workflow skills

The discipline and output skills are packaged separately from `commands/`: [efficient](/docs/skills/efficient), [lean tools](/docs/skills/lean-tools), [search](/docs/skills/search), [cost refactor](/docs/skills/cost-refactor), and [genome author](/docs/skills/genome-author). They are not included in the command count above.

## Removed commands

The old `/ashlr-context-status`, `/ashlr-usage`, `/ashlr-errors`, and `/ashlr-recall` commands were removed in v1.30. No redirect stubs ship. Use `/ashlr-status --context`, `/ashlr-dashboard --by-tool`, and `/ashlr-doctor --errors` for the first three. For recall, use your editor's memory system and `/ashlr-handoff`.
