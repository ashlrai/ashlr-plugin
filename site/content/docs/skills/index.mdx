## Slash commands

### /ashlr-allow

Auto-approve every ashlr MCP tool so Claude Code stops prompting in bypass-permissions mode.

### /ashlr-benchmark

Run the ashlr-plugin token-savings benchmark against the current project.

### /ashlr-brief

Toggle response-shortening (caveman-inspired, ashlr-flavored) with three intensity levels. Trims filler from Claude's prose to save 30–55% on output tokens while keeping code blocks, errors, and destructive-action confirmations in full grammar.

### /ashlr-budget

Set, check, or clear a session spend cap. Guards against runaway tool use in long sessions.

### /ashlr-compact

Identify stale tool results accumulating in the conversation history and surface a recompression plan.

### /ashlr-dashboard

Rich token-savings dashboard ; per-tool bar charts, 7d/30d sparklines, projected annual savings, and cost in dollars.

### /ashlr-doctor

Diagnose an ashlr-plugin install ; checks plugin path, version, MCP servers, hooks, stats, genome, and settings in under 10 seconds.

### /ashlr-eco-mode

Toggle eco mode ; aggressive token-saving behaviors that trade some response richness for lower session cost.

### /ashlr-fleet

Explain the Phantom fleet pane, local peers, and governed Claude model routing.

### /ashlr-genome-init

Initialize a `.ashlrcode/genome/` in the current project so ashlr__grep can route through genome RAG for ~-84% token savings.

### /ashlr-genome-keygen

Generate an X25519 keypair for team-cloud genome v2 encryption and register the public half with Ashlr. Run this once per machine before running /ashlr-genome-team-init. Safe to re-run ; a no-op when the machine's key is already registered.

### /ashlr-genome-loop

Inspect and control the automatic genome propose + consolidate loop (PostToolUse observer + SessionEnd consolidator).

### /ashlr-genome-push

Push the local .ashlrcode/genome/ to the team cloud. Safe to run any time; invoked automatically at SessionEnd after consolidation. No-op when the repo has no .cloud-id (i.e. team-genome not initialized) or when ASHLR_CLOUD_GENOME_DISABLE=1.

### /ashlr-genome-rewrap

Re-wrap the team-cloud genome DEK for every member with a current pubkey. Run this after a teammate rotates their keypair (/ashlr-genome-keygen --force) or joins the team and runs /ashlr-genome-keygen for the first time. Admin-only.

### /ashlr-genome-team-init

Initialize (or rewrap for new members of) a team-cloud genome for the current repo. One-time per repo by an admin; then teammates join via /ashlr-team-invite + /ashlr-genome-keygen + admin re-runs with --wrap-all.

## Workflow skills

### ashlr-brief

Tunable response-shortening skill for Claude Code. Trims filler from prose to reduce output tokens 30–55% while preserving grammar and code fidelity. Three intensity levels (lite / standard / concise). Auto-clarity exceptions for security, destructive actions, errors, and code blocks.

### ashlr-codex-doctor

Check Ashlr's Codex plugin packaging, MCP manifest, hooks, skills, and workspace allow-list. Use when Codex setup, plugin loading, or MCP registration looks wrong.

### ashlr-codex-efficient-tools

Codex-native efficient tool workflow. Prefer Ashlr MCP read, grep, tree, bash, savings, and genome tools before native scans when they reduce context.

### ashlr-codex-genome-refresh

Refresh or maintain Ashlr project genome state from Codex. Use after architectural changes, schema/routing changes, or substantial refactors.

### ashlr-codex-parallel-explore

Efficient parallel exploration habits for Codex. Use when a task needs several independent codebase questions answered before implementation.

### ashlr-codex-savings

Inspect Ashlr token savings from Codex using host-neutral CLI and MCP surfaces.

### ashlr-cost-refactor

Token-efficient refactoring discipline for Claude Code. Diff-first before editing, structural edits for renames, find-all-refs then one multi_edit per file, no re-reads between edits, one genome proposal at the end. Reduces refactor session cost 40–65%.

### ashlr-efficient

Output structure reshaper for Claude Code. Complements ashlr-brief's prose trimming by enforcing inverted-pyramid order, inline code for identifiers, tables for multi-item comparisons, and no transitional filler. Works standalone or alongside ashlr-brief.

### ashlr-genome-author

Guidelines for when and how to call ashlr__genome_propose to keep the project genome accurate. Covers post-architectural-decision proposals, correct summary format, and what NOT to propose. Keeps the genome signal-rich without noise.

### ashlr-lean-tools

Highest-impact token-saving habits for Claude Code tool use. Read-once, batch edits, orient-before-search, skip verification reads, grep-before-read, concise output at high spend. Reduces session token cost 30–60%.

### ashlr-search

Genome-aware search habits for Claude Code. Prefer ashlr__grep and ashlr__glob over native scans; compose multi-term queries; trust genome summaries; orient once before searching. Reduces redundant reads and search token cost 40–70%.
