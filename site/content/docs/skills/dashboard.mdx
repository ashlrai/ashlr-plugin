## When to use

When you want a detailed breakdown of savings across tools, time periods, and projects : more than `/ashlr-savings` provides.

## What it does

Runs `bun run ${CLAUDE_PLUGIN_ROOT}/scripts/savings-dashboard.ts` and prints stdout verbatim. The script reads `~/.ashlr/stats.json` and renders a multi-panel view:

1. Banner plus an at-a-glance tile strip: session, lifetime, and best day
2. Per-tool bar chart (top 8 tools by tokens saved)
3. 7-day and 30-day activity sparklines
4. Projected annual savings extrapolated from the last 30 days
5. Top 3 projects from `~/.ashlr/session-log.jsonl`
6. Extra sections when data exists: where savings come from, adoption funnel, streak, hook timings, and nudges

`--by-tool` appends a per-tool session-log report; `--watch` redraws the dashboard every 1.5 seconds.

## Output

With no recorded savings yet:

```
  no savings recorded yet : run /ashlr-demo to see the plugin in action.

  stats path: ~/.ashlr/stats.json
  use ashlr__read, ashlr__grep, or ashlr__edit to start.
```
