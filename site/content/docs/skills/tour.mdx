## When to use

First run after install, when onboarding a teammate, or as a sanity check after upgrading.

## What it does

The agent runs six steps in order on your real project files:

0. **Status-line legend**: runs `/ashlr-legend` and shows its output verbatim
1. **Current state**: runs `/ashlr-status` (or reads `~/.ashlr/stats.json`) and sums up in one line what ashlr sees: MCP servers active, genome present or not, lifetime tokens saved
2. **Tree view**: calls `ashlr__tree` on the current directory, the compressed structure the model gets instead of many `ls` and `Read` calls
3. **Read a real file**: picks the largest TypeScript file (skipping `node_modules`, `dist` and `.git`), calls `ashlr__read`, and compares the returned size with `wc -c`
4. **Show the receipts**: calls `ashlr__savings` and shows the totals block verbatim
5. **Next steps**: ends with exactly three suggestions:
   - ask a real question with `ashlr__grep`
   - run `/ashlr-genome-init` so grep can use the genome
   - run `/ashlr-settings set statusLine true` to keep savings in the status line

## Output style

Each step gets at most two sentences of second-person narration, with tool output in a fenced block where the step calls for it. Total narration stays under 60 lines. The tour runs no tools outside this sequence; if a step fails (no TypeScript files, an MCP server down) it notes that in one line and moves on.
