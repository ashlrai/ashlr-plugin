## When to use

Before running [`/ashlr-genome-init --summarize`](/docs/skills/genome-init), so the genome summarizes discovered projects with a fast local model. Pro and Team users can skip Ollama: with `~/.ashlr/pro-token` present, summarization routes to the hosted model (see [Hosted summarization](/docs/pro/hosted-summarization)). Ollama stays the path for the free tier and offline use.

## What it does

The command runs `bun run ${CLAUDE_PLUGIN_ROOT}/scripts/ollama-setup.ts` and relays its output verbatim. The script:

1. Checks that Ollama is installed and the daemon is reachable
2. Lists the installed models
3. If no recommended model is installed, prints the `ollama pull` command, or pulls the top pick itself with `--yes`
4. Warns when every installed model is 20B parameters or larger, since those time out on summaries
5. Smoke-tests the chosen model with a one-sentence prompt under a 30-second timeout

It does not change any ashlr settings.

## Recommended models

| Model | Size | Note |
|---|---|---|
| `llama3.2:3b` | ~2 GB | recommended default — fastest, good quality |
| `llama3.2:1b` | ~1.3 GB | tiny, acceptable fallback |
| `qwen2.5:3b` | ~2 GB | alternative |
| `phi3.5:3.8b` | ~2.2 GB | alternative |

## Flags

| Flag | Effect |
|---|---|
| `--yes` | Pull `llama3.2:3b` without prompting. `ASHLR_OLLAMA_AUTO=1` does the same. Say "auto" or "just install it" and the command adds it |

## Output

With Ollama running but no models installed:

```
ashlr ollama-setup

[ok] Ollama is installed and running
[!] no models installed
[!] no fast recommended model installed (llama3.2:3b is the recommended default)

  recommended models (pick one):
    llama3.2:3b      ~2 GB      recommended default — fastest, good quality
    llama3.2:1b      ~1.3 GB    tiny, acceptable fallback
    qwen2.5:3b       ~2 GB      alternative
    phi3.5:3.8b      ~2.2 GB    alternative

[i] to install the recommended model, run:
    fix: ollama pull llama3.2:3b

[i] or re-run with --yes to install automatically:
    fix: bun run scripts/ollama-setup.ts --yes
```

In a color terminal the markers print as `✓`, `✗`, `⚠` and `ℹ`; in pipes they fall back to `[ok]`, `[x]`, `[!]` and `[i]`. When the smoke test passes, the last line confirms that `/ashlr-genome-init --summarize` will use the model.

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Ollama installed and running, recommended model present, smoke test passed |
| `1` | Something you can fix: not installed, not running, no model, or smoke test failed. The output names the next command |
| `2` | Internal error |
