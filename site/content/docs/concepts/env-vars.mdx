---
title: Environment variables reference
description: Complete reference for all ASHLR_* environment variables — defaults, purpose, and which component reads each one.
---

All runtime behavior in ashlr-plugin can be tuned through environment variables. Set them in your shell profile, `.env`, or directly before the MCP entrypoint command. None are required for basic operation.

## Core behavior

| Variable | Default | Description |
|---|---|---|
| `ASHLR_HOOK_MODE` | `redirect` | PreToolUse hook behavior. `redirect` — intercept native Read/Grep/Edit and deny with "use ashlr__* instead". `nudge` — print a suggestion but allow the native call. `off` — hooks fire but do nothing. |
| `ASHLR_ROUTER_DISABLE` | unset | Set to `1` to revert to legacy per-server mode (kill-switch, one release cycle only). |
| `ASHLR_MCP_HOST` | `generic` via CLI launchers | MCP host identifier. Set explicitly to `claude-code`, `codex-cli`, `cursor`, `cline`, `claude-desktop`, `gemini-cli`, or `generic`. A directly launched router can infer Claude Code from nonempty Claude environment signals when this is unset. Affects host-specific side effects. |
| `ASHLR_CODEX_HOOK_MODE` | `nudge` | Codex hook behavior. `nudge` injects `additionalContext`, `off` disables Codex nudges, and `redirect` is reserved for proven redirect-compatible hooks. |
| `ASHLR_DEBUG` | unset | Set to `1` to enable verbose logging from all servers to stderr. |
| `ASHLR_VERSION` | (from plugin.json) | Override the reported version string. |
| `ASHLR_PHANTOM_PREFLIGHT` | unset | Set to `1` (or `true`, `on`) to make the doctor also run Phantom's value-free `phantom agent doctor --json --strict`: blocked fails, degraded or unknown warns. `strict` fails on anything but ready. A missing `phantom` is only a warning. See [docs/phantom-preflight.md](https://github.com/ashlrai/ashlr-plugin/blob/main/docs/phantom-preflight.md). |

## Hooks

| Variable | Default | Description |
|---|---|---|
| `ASHLR_TASK_PASSTHROUGH` | unset | Set to `1` to let native `TaskList` and `TaskGet` through instead of redirecting them to `ashlr__task_list` and `ashlr__task_get`. |
| `ASHLR_EDIT_MIN_CHARS` | `80` | Minimum combined length of `old_string` and `new_string` before the Edit hook redirects to `ashlr__edit`. Smaller edits pass through to native Edit. |
| `ASHLR_ENFORCE` | unset | Legacy. Set to `1` to make the Read, Grep and Edit hooks block with exit code 2 and a stderr message, independent of `ASHLR_HOOK_MODE`. |
| `ASHLR_NO_ENFORCE` | unset | Set to `1` to turn off the legacy `ASHLR_ENFORCE=1` blocking. |
| `ASHLR_HOOK_TIMEOUT_MS` | `2000` | Safety-net timeout for each hook process. A hook that runs longer exits 0 so it never blocks the tool call. |
| `ASHLR_HOOK_TIMINGS` | on | Set to `0` to stop writing `~/.ashlr/hook-timings.jsonl`, the data behind `/ashlr-hook-timings`. |
| `ASHLR_BLOCK_WINDOW_MS` | `10000` | How long after a redirected native call a matching `ashlr__*` call still counts as converted in the session log. |
| `ASHLR_PERMISSIONS_CONSENT` | unset | Set to `skip` so the session-start hook never adds the ashlr tool wildcard to the Claude Code allow list. |
| `ASHLR_QUIET` | unset | Set to `1` to silence the session-start greeting (welcome box, last-session savings line and weekly summary). Session state is still recorded. |
| `ASHLR_NO_GREET` | unset | Set to `1` to skip the session-start greeting but keep its state updates. |

## Edit tools

| Variable | Default | Description |
|---|---|---|
| `ASHLR_EDIT_FUZZY` | on | Set to `off` to stop `ashlr__edit` and `ashlr__multi_edit` from falling back to a confident, unique fuzzy match when a strict search has no exact match (files up to 2 MB). |
| `ASHLR_EDIT_VALIDATE` | unset | Set to `block` to refuse an edit that introduces a syntax error. By default such an edit is still written. |

## Storage paths

| Variable | Default | Description |
|---|---|---|
| `ASHLR_HOME_OVERRIDE` | `$HOME` | Home directory that contains `.ashlr/` (`stats.json`, `session-log.jsonl`, caches). Intended for tests and sandboxes; normal installs leave it unset. |
| `ASHLR_SESSION_LOG` | unset | Set to `0` to stop writing `~/.ashlr/session-log.jsonl` and session events. It is a kill switch, not a path. |
| `ASHLR_STATS_BACKEND` | `json` | Stats storage backend. `json` uses `~/.ashlr/stats.json`. `sqlite` uses `~/.ashlr/stats.db` (SQLite, lower contention under heavy parallel load). |
| `ASHLR_STATS_DB_PATH` | `~/.ashlr/stats.db` | Path to the SQLite DB when `ASHLR_STATS_BACKEND=sqlite`. |
| `ASHLR_CONTEXT_DB_DISABLE` | unset | Set to `1` to disable the SQLite context tracking DB. |

## Session accounting

| Variable | Default | Description |
|---|---|---|
| `ASHLR_SESSION_ID` | (from `CLAUDE_SESSION_ID`) | Session bucket key. Inherited from the Claude Code harness. Override to isolate test sessions. |
| `ASHLR_PRICING_MODEL` | `sonnet-4.6` | Model used to compute cost savings. When unset, ashlr uses `CLAUDE_CODE_MODEL` (with any `claude-` prefix removed) and then `sonnet-4.6`. Options: `sonnet-4.6`, `sonnet-4.5`, `opus-4.7`, `opus-4`, `haiku-4.5`. Unknown names fall back to `sonnet-4.6` pricing. |
| `ASHLR_SESSION_BUDGET_TOKENS` | unset | Soft token budget for the session. When exceeded, `/ashlr-status` shows a warning. |
| `ASHLR_SESSION_BUDGET_USD` | unset | Soft cost budget for the session in USD. |
| `ASHLR_ECO` | unset | Set to `1` to enable eco mode — reduces hook frequency and disables background prefetch. |
| `ASHLR_CALIBRATE` | unset | Set to `1` to re-run tokenizer calibration against `ANTHROPIC_API_KEY` on startup. |
| `ASHLR_STATS_UPLOAD` | unset | Set to `0` to stop uploading lifetime stats. When `ASHLR_PRO_TOKEN` is set, stats upload at most once every 5 minutes unless this is `0`. |
| `ASHLR_STATS_SYNC` | unset | Set to `1` to write `stats.json` on every update instead of debouncing writes. Local only; it does not contact the cloud. |
| `ASHLR_DISABLE_DIGEST` | unset | Set to `1` to suppress the end-of-session savings digest. |
| `ASHLR_TUNING` | on | Set to `off` to stop per-repo self-tuning of compression detail and the local miss counts it learns from. Local only, counts only. |

## Summarization and LLM

| Variable | Default | Description |
|---|---|---|
| `ASHLR_LLM_PROVIDER` | `auto` | LLM provider for summarization: `auto`, `anthropic`, `cloud`, `onnx`, `local` or `off`. `auto` prefers `local` when `ASHLR_LLM_URL` is set, then tries `anthropic` (`ANTHROPIC_API_KEY`), `cloud`, `onnx` and `local`. `local` uses `ASHLR_LLM_URL` (LM Studio or Ollama). |
| `ASHLR_LLM_URL` | `http://127.0.0.1:1234/v1` | Endpoint for the local LLM summarizer (LM Studio / Ollama). |
| `ASHLR_LLM_KEY` | unset | API key for the LLM endpoint (if required). |
| `ASHLR_LLM_MODEL` | unset | Model name to pass to the LLM endpoint. |
| `ANTHROPIC_API_KEY` | unset | When set, enables API-measured token counting (fire-and-forget `measureTokens()` calls). Also used when `ASHLR_LLM_PROVIDER=anthropic`. |

## Genome

| Variable | Default | Description |
|---|---|---|
| `ASHLR_GENOME_AUTO` | `1` | Set to `0` to disable the auto-propose hook that runs after every Write/Edit. Genome still exists; it just won't auto-update. |
| `ASHLR_GENOME_RETRIEVAL` | `on` | Set to `off` to disable genome-backed grep routing. `ashlr__grep` falls back to ripgrep. Useful when debugging or the genome is stale. |
| `ASHLR_GENOME_LOCAL_SEQ_PATH` | (derived from cwd) | Override the genome sequential-read path for testing. |
| `ASHLR_EMBED_URL` | unset | Endpoint for the embedding model (ONNX server). Used by genome similarity search. |
| `ASHLR_EMBED_THRESHOLD` | `0.68` | Cosine similarity threshold for genome section retrieval. Lower = more results, higher = stricter matching. |
| `ASHLR_EMBED_MODEL` | unset | Embedding model name override. |
| `ASHLR_EMBED_FORMAT` | `ollama` | Set to `openai` to call an OpenAI-compatible `/v1/embeddings` endpoint (for example LiteLLM) at `ASHLR_EMBED_URL`. Opt-in; https, or http only to `127.0.0.1` / `[::1]`, no redirects. |
| `ASHLR_EMBED_KEY` | unset | Optional Bearer key for `ASHLR_EMBED_FORMAT=openai`. A Phantom `phm_` placeholder is sent unchanged; never logged. |
| `ASHLR_PREFETCH` | `1` | Set to `0` to disable background prefetch warming on `ashlr__read` calls (Pro). |
| `ASHLR_GENOME_REQUIRE_OVERLAP` | on | Set to `0` to turn off the auto-propose relevance gate. By default, once the genome manifest has 3 or more sections, an auto-observation is written only when it shares a word with a section title, summary or tag. |
| `ASHLR_GENOME_LLM_SYNTHESIS` | auto | Session-end consolidation runs new proposals through an LLM when an endpoint is reachable (`ASHLR_LLM_URL`, `ANTHROPIC_API_KEY` or `OPENAI_API_KEY`), otherwise it uses deterministic dedup. Set to `1` to always try the LLM, or `0` to never use it. |
| `ASHLR_CLOUD_GENOME_DISABLE` | unset | Set to `1` to turn off the team-cloud genome: no pull into the `~/.ashlr/genomes/` cache at session start and no push at session end. See [docs/cloud-genome.md](https://github.com/ashlrai/ashlr-plugin/blob/main/docs/cloud-genome.md). |
| `ASHLR_OLLAMA_AUTO` | unset | Set to `1` so `/ashlr-ollama-setup` pulls the recommended model without prompting, the same as `--yes`. |

## Pro / Cloud

| Variable | Default | Description |
|---|---|---|
| `ASHLR_PRO_TOKEN` | unset | Bearer token for `api.ashlr.ai`. Set after running `/ashlr-upgrade`. Enables cloud genome sync, hosted summarization, and stats upload. |
| `ASHLR_PRO_ASSUME` | unset | Set to `1` to assume Pro tier without verifying the token (testing only). |
| `ASHLR_API_URL` | `https://api.ashlr.ai` | Override the Pro backend URL. Use for self-hosted enterprise deployments. |
| `ASHLR_CLIENT_ID` | unset | OAuth client ID for the Pro auth flow. |
| `ASHLR_TEAM_GENOME_ID` | unset | Team genome identifier. Set automatically by `/ashlr-genome-team-init`. |
| `ASHLR_KEYCHAIN` | on | Set to `0` to keep `ASHLR_PRO_TOKEN` out of the OS keychain (macOS `security`, Linux `secret-tool`) and use only the `0600` `~/.ashlr/env` file. |
| `ASHLR_POLICY_ENFORCE` | on | Set to `0` to turn off the policy hook. When `ASHLR_PRO_TOKEN` is set, it fetches the policy from the Pro backend before Edit, Write, Bash and MultiEdit calls and applies its deny and require-confirm rules. |
| `ASHLR_NO_BROWSER` | unset | Set to `1` so `/ashlr-upgrade` prints the sign-in and checkout URLs instead of opening a browser (SSH, CI, headless). |
| `ASHLR_SITE_URL` | `https://plugin.ashlr.ai` | Override the website URL that `/ashlr-upgrade` links to. |

## Telemetry

| Variable | Default | Description |
|---|---|---|
| `ASHLR_TELEMETRY` | unset | Set to `on` to opt into anonymous usage telemetry. Telemetry is **off by default**. What's sent: opaque session hash, tool call counts, no paths or content. See `docs/telemetry.md` for the full contract. |
| `ASHLR_TELEMETRY_URL` | `https://telemetry.ashlr.ai/v1/events` | Override the endpoint that opted-in telemetry is flushed to. |

## Pulse (self-hosted observability)

The `hooks/pulse-emit.ts` PostToolUse hook exits immediately unless `ASHLR_PULSE_OTLP_ENDPOINT` is set. It sends no prompts, completions, paths or tool inputs; the project folder is sent only as a hash.

| Variable | Default | Description |
|---|---|---|
| `ASHLR_PULSE_OTLP_ENDPOINT` | unset | OTLP/HTTP traces URL of your own Pulse server, for example `http://host/api/otlp/v1/traces`. When set, the hook sends one span per tool call. |
| `ASHLR_PULSE_PAT` | unset | Bearer token minted on the Pulse server. Production servers require it. |
| `ASHLR_PULSE_USER` | `$USER`, else `dev-local` | Value of the `x-ashlr-user` header sent when `ASHLR_PULSE_PAT` is unset. Development servers only. |
| `ASHLR_PULSE_TIMEOUT_MS` | `1500` | Timeout for each span POST. |

## UI / status line

| Variable | Default | Description |
|---|---|---|
| `ASHLR_STATUS_ANIMATE` | `1` | Set to `0` to disable status-line gradient animation. Useful in CI or terminals that don't support truecolor. |
| `ASHLR_DISABLE_MILESTONES` | unset | Set to any value other than `0` to stop the status line's one-time savings celebrations (first saved call, 10k lifetime tokens). |

## Access control

| Variable | Default | Description |
|---|---|---|
| `ASHLR_ALLOW_PROJECT_PATHS` | unset | Extra workspace roots the MCP server may access outside the launch cwd. Use absolute paths, separated by `:` on Unix or `;` on Windows. |
| `ASHLR_LAUNCH_CWD` | (set by the launchers) | The folder the host started the MCP server in. The launchers record it before moving into the plugin directory, and the router adopts it as the project root. Leave it unset; it is listed so you recognize it in a process environment. |
| `ASHLR_HTTP_ALLOW_PRIVATE` | unset | Set to `1` to allow `ashlr__http` to access private/LAN hosts (e.g. `localhost`, `192.168.*`). Blocked by default for safety. |
| `ASHLR_REQUIRE_GH_CONFIRM` | unset | Set to `1` to require explicit confirmation before any GitHub write operation (`ashlr__issue_create`, `ashlr__pr_approve`, etc.). |
| `ASHLR_GATEWAY_STRICT` | unset | Set to `1` (or `true`, `yes`, `on`) to send a model request that carries a key only to `127.0.0.1` or `[::1]`, to a host in `ASHLR_GATEWAY_HOSTS` over https, or to `api.anthropic.com`, `api.openai.com` or `api.ashlr.ai` on 443. Redirects and credentials in the URL are refused. |
| `ASHLR_GATEWAY_HOSTS` | unset | Comma-separated exact `host:port` entries allowed under `ASHLR_GATEWAY_STRICT`, for example a LiteLLM gateway. |

## Experimental

| Variable | Default | Description |
|---|---|---|
| `ASHLR_PIPE_ENABLE` | unset | Set to `1` to register the experimental `ashlr__pipe` tool. It is excluded from the default tool count. See [`ashlr__pipe`](/docs/tools/pipe). |
| `ASHLR_PIPE_ALLOW_BASH` | unset | Set to `1` to allow `bash()` calls inside `ashlr__pipe` expressions. Requires `ASHLR_PIPE_ENABLE=1`. |
| `ASHLR_ORCHESTRATE_REAL_LLM` | unset | Set to `1` to use a real LLM for orchestration graph expansion (instead of the stub). |

## No-install

| Variable | Default | Description |
|---|---|---|
| `ASHLR_NO_AUTO_INSTALL` | unset | Set to `1` to stop the launchers from installing Bun when it is not on `PATH` or in `~/.bun/bin`. |
