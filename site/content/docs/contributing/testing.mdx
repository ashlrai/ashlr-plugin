## Test runner

ashlr uses [Bun's built-in test runner](https://bun.sh/docs/cli/test). Plugin tests live under `__tests__/`. Run the root wrapper to use the repository's worker isolation settings.

## Run all tests

```sh
cd /path/to/ashlr-plugin
HOME=$(mktemp -d) bun run test
```

## Run a specific test file

```sh
HOME=$(mktemp -d) bun test __tests__/efficiency-server.test.ts
```

## Run tests matching a pattern

```sh
HOME=$(mktemp -d) bun test __tests__ --test-name-pattern "snipCompact"
```

## Test organization

```
__tests__/
  efficiency-server.test.ts   ashlr__read, ashlr__grep, ashlr__edit
  bash-server.test.ts         ashlr__bash, output compression
  diff-server.test.ts         ashlr__diff modes (stat/summary/full)
  diff-semantic-server.test.ts rename detection, signature change
  glob-server.test.ts         git ls-files vs readdir fallback
  orient-server.test.ts       routing, keyword extraction
  ask-server.test.ts          question routing table
  genome-server.test.ts       propose/consolidate cycle
  stats-server.test.ts        stats read/write/merge
  command-docs.test.ts        docs/commands.md vs shipped commands + CLI dispatch
  docs-freshness.test.ts      command/tool inventories and schema arguments
```

## Writing a new test

```typescript
import { describe, it, expect } from "bun:test";
import { myFunction } from "../servers/my-server";

describe("myFunction", () => {
  it("does the thing", () => {
    expect(myFunction("input")).toBe("expected output");
  });
});
```

Tests that need the filesystem should use `tmp` directories created with `mkdtemp` and cleaned up in `afterAll`.

## Documentation checks

```sh
HOME=$(mktemp -d) bun test __tests__/docs-freshness.test.ts __tests__/command-docs.test.ts __tests__/router-lazy-handshake.test.ts
(cd site && bun run gen-docs)
bun run mdx-lint
```

The freshness test compares the command index with `commands/*.md`, tool indexes with handler declarations in `servers/`, and matrix arguments with the tool catalog. `command-docs.test.ts` keeps `docs/commands.md` in step with the shipped commands and CLI dispatch. The handshake suite checks the catalog against live registration. `gen-docs` regenerates generated docs (skills index, help, tools index, capabilities matrix, install/release pages) from source. Keep `server/` (the cloud backend) separate from plugin tool source in `servers/`.

## CI

Tests run on every push via GitHub Actions (`.github/workflows/ci.yml`). The matrix covers Linux, macOS, and Windows runners.

## Type checking

```sh
bun run typecheck
```

This runs `tsc --noEmit` on the plugin root `tsconfig.json`. Always pass typecheck before opening a PR.
