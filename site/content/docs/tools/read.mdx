---
title: ashlr__read
description: Read files with compact head and tail output or AST summaries.
---

`ashlr__read` reads a file and returns a compact representation. In `auto` mode, large files in supported languages can use an AST skeleton; other reads use snipCompact head and tail output. Large results may also use summarization when a provider is available.

## Input schema

| Field | Type | Required | Description |
|---|---|---|---|
| `path` | `string` | yes | Absolute or working-directory-relative file path |
| `bypassSummary` | `boolean` | no | Skip LLM summarization; snipCompact truncation still applies |
| `mode` | `string` | no | `auto` (default), `ast`, or `snip` |

## Example

```text
Use ashlr__read to read servers/read-server.ts
```

The output may include a confidence badge. See [confidence badges](/docs/concepts/confidence-badges) and the [benchmark methodology](/docs/concepts/savings-math) for interpretation.
