---
title: ashlr__test
description: "Run a test suite and parse output : bun/vitest/jest/pytest/go test. Compresses runner noise into one failure block per failure."
---

`ashlr__test` runs a test command and returns a structured summary: pass/fail counts, per-failure blocks (test name + error + stack), and timing. Passes, setup output, and progress bars are stripped.

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `command` | string | no | Full command to run verbatim (e.g. `bun test src/foo.test.ts`). Overrides runner + files. |
| `cwd` | string | no | Working directory (default: cwd). Must be inside the current cwd. |
| `files` | array | no | Specific test file paths to pass to the runner. |
| `runner` | string | no | Test runner to use. `auto` detects from package.json / go.mod / pytest.ini (default: `auto`). |
| `failuresOnly` | boolean | no | Return only failure details, not per-test pass output (default: true). |
| `bypassSummary` | boolean | no | Show all failures instead of truncating at 2 inline (default: false). |
| `watch` | boolean | no | Run tests once, then fork into a background watch session that re-runs on source file changes (debounced 200ms). |
| `grep` | string | no | Test name filter (informational label stored on the watch session). |

## Supported runners

`runner: "auto"` (the default) detects the runner from `package.json`, `go.mod`, or `pytest.ini`. Explicit values: `bun`, `vitest`, `jest`, `pytest`, `go`. Any other command falls back to a generic parser.

## Typical output

```
Tests: 3 failed, 142 passed (145 total) : 1.8s

FAIL  src/auth/handler.test.ts > handleAuthRequest > returns 401 on bad token
  AssertionError: expected 200 to equal 401
    at handler.test.ts:42:18

FAIL  src/auth/handler.test.ts > handleAuthRequest > logs the attempt
  Error: spy not called
    at handler.test.ts:61:5
```

## Typical savings

−70–85% vs raw test runner stdout. Large test suites often print thousands of lines of progress; `ashlr__test` compresses that to one block per failure.
