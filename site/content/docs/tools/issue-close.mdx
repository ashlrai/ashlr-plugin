---

`ashlr__issue_close` closes a GitHub issue via the `gh` CLI.

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `issue` | number | yes | Issue number. |
| `comment` | string | no | Optional closing comment. |
| `reason` | string | no | Optional close reason. |
| `repo` | string | no | `owner/repo` (default: auto-detect from cwd git remote). |
| `confirm` | boolean | no | Required when `ASHLR_REQUIRE_GH_CONFIRM=1`. |

## Notes

- Requires `gh` CLI to be installed and authenticated.
- Set `ASHLR_REQUIRE_GH_CONFIRM=1` to require explicit confirmation before closing.
- Closing is not reversible via this tool : reopen through the GitHub UI or `gh issue reopen`.
