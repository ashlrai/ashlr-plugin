---
title: ashlr__grep
description: Genome-aware search with a ripgrep fallback.
---

`ashlr__grep` searches using genome sections and, when available, matching merged PRs and closed issues. When genome retrieval is unavailable or does not produce a result, it falls back to ripgrep. Large ripgrep results can be summarized.

## Input schema

| Field | Type | Required | Description |
|---|---|---|---|
| `pattern` | `string` | yes | Query or regex |
| `cwd` | `string` | no | Working directory (default: process working directory) |
| `bypassSummary` | `boolean` | no | Skip LLM summarization and return ripgrep output as-is |
| `include_prs` | `boolean` | no | Include matching merged PRs from the cloud genome (default: true) |
| `include_issues` | `boolean` | no | Include matching closed issues from the cloud genome (default: true) |
| `since_days` | `number` | no | Filter PRs and issues older than this many days; no filter by default |

## Example

```text
Use ashlr__grep to find all calls to recordSaving in servers/
```

The [benchmark methodology](/docs/concepts/savings-math) describes measured savings and their limits.
