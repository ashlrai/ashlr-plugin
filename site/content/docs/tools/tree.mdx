**Server:** `ashlr-tree` — `servers/tree-server.ts`

Returns a Unicode box-drawing tree of the project structure in a single call. Inside a git repo, uses `git ls-files` so `.gitignore` is honored for free. Outside git, uses a readdir walk with a hardcoded exclusion set (`node_modules`, `.git`, `dist`, `.cache`, etc.).

## Input schema

| Field | Type | Required | Description |
|---|---|---|---|
| `path` | `string` | no | Directory to scan (default: cwd) |
| `depth` | `number` | no | Max traversal depth (default: 4) |
| `pattern` | `string` | no | Only include files matching this regex (e.g. '\\.ts$') |
| `exclude` | `string[]` | no | Directory names to skip (default: node_modules, dist, build, .git, .next, .cache, .turbo, __pycache__, .venv, .DS_Store) |
| `sizes` | `boolean` | no | Include file sizes shown as B/KB/MB (default: true) |
| `loc` | `boolean` | no | Include line counts for text files (default: false; skips files over 2 MB) |
| `maxEntries` | `number` | no | Hard cap on entries returned (default: 500). When exceeded, per-dir truncation with count. |

## Output format

```
ashlr-plugin/
├── servers/
│   ├── efficiency-server.ts
│   ├── bash-server.ts
│   └── ...
├── commands/
│   └── ...
└── scripts/
    └── ...
[312 files total · git ls-files]
```

## Example

```
Use ashlr__tree on the current project
```

## Savings baseline

Replaces 3–10 `ls` calls + mental assembly. A typical project returns in one call what would take 5 calls to map manually.
