**Server:** `ashlr-genome` — `servers/genome-server.ts`

The active genome scribe loop. Three tools that let an agent propose, consolidate, and inspect evolutionary updates to the project genome stored under `.ashlrcode/genome/`.

## Tools

### ashlr__genome_propose

Queue a proposed update to a genome section.

| Field | Type | Required | Description |
|---|---|---|---|
| `section` | `string` | yes | Genome section name (e.g. `architecture`, `patterns`) |
| `content` | `string` | yes | Proposed content to merge into the section |
| `operation` | `"append"` \| `"update"` \| `"create"` | no | How to apply the content (default: append) |
| `rationale` | `string` | yes | Why this change; 1-3 sentences |
| `cwd` | `string` | no | Override working directory (default: process.cwd()) |

### ashlr__genome_consolidate

Merge pending proposals into the genome. Optionally uses an OpenAI-compatible LLM for smart merging.

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | `string` | no | Pass 'none' to force offline sequential-apply, or any other value (for example 'llm') to merge with the LLM configured by $ASHLR_LLM_URL (default local LM Studio at 127.0.0.1:1234). The value is never used as an endpoint. If omitted, uses the LLM only when $ASHLR_LLM_URL or $ASHLR_LLM_KEY is set. |
| `cwd` | `string` | no | Override working directory |

### ashlr__genome_status

Compact report of pending proposals and recent mutations.

| Field | Type | Required | Description |
|---|---|---|---|
| `cwd` | `string` | no | Override working directory |

## Output format (status)

```
Genome: .ashlrcode/genome/  ·  4 sections  ·  2 pending proposals

Pending:
  architecture  (proposed 3m ago from servers/efficiency-server.ts)
  patterns      (proposed 1m ago from scripts/genome-propose.ts)

Recent mutations:
  2024-01-15 09:23  architecture  merged 1 proposal
```
